I'm a platform / SRE engineer at Apple Ad Platforms. I operate the Apache Airflow fleet a lot of pipelines depend on, spread across Kubernetes (EKS) and on-prem. I like the unglamorous parts of the job: turning a 2 a.m. incident into permanent tooling, and writing code that's honest about what it does *and* what it doesn't.
