  ## 📌 Featured Projects                                                                                                                                                                                                    
                         
  ### 🌐 [Portfolio Backend](https://github.com/SushrutVaidya/Portfolio-Backend)                                                                                                                                             
  Production REST API powering [sushrutvaidya.in](https://sushrutvaidya.in):    
  - **Spring Boot 4.x** on Java 17 with PostgreSQL (JPA/Hibernate) and Redis (Upstash, SSL)                                                                                                                                  
  - Redis-backed counters with `AtomicInteger` fallback — degrades gracefully when cache is unavailable                                                                                                                      
  - Time-slotted audio selection: server clock maps to different tracks across 6 daily windows                                                                                                                               
  - Idempotent UUID-based user registration for leaderboard — no auth required                                                                                                                                               
  - GitHub Actions CI/CD: compile → test → package → JAR verification on every push                                                                                                                                          
  - Deployed on **AWS EC2** behind **Nginx** reverse proxy with **SSL/HTTPS** via Docker
